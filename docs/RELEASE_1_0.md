# 1.0.0 — attributed Eteocretan reading archive

Twelve reading versions for eight named inscriptions: four historical primary
versions from the three Praisos inscriptions, plus eight separately excluded
secondary reference versions. Historical source-page evidence, exact source
locators, structured object/version identities, JSON/JSONL/CSV exports and
an eleven-entry coverage register are included.

Unreviewed historical encodings, secondary transcriptions and disputed
objects are not analytically admitted. The zero frequency result preserves
this boundary. Dreros primary editions, modern critical reconciliation,
Azoria inventory and independent collation remain explicit next gates.

Offline source replay, negative integrity tests and export roundtrip verify
the archive. They do not establish epigraphic accuracy, exhaustive coverage
or a decipherment. Data/metadata CC BY-SA 4.0; code MIT; public-domain
historical originals retain their status. Cite original sources and this release.
