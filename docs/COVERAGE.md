# Coverage and admission policy

The release archives three historical Praisos inscriptions in four versions
and eight separate secondary reference versions. This is a usable source
archive and concordance scaffold, not a complete modern critical corpus.
The register has eleven entries: Praisos 1–6, Dreros 1–2, disputed Psychro,
disputed Arkalochori and an Azoria collection lead.

Do not use the frequently repeated five-inscription overview as an exhaustive
inventory: the excavation literature and fragmentary candidates require a
larger, source-specific discovery register. Azoria is retained because the
excavation report itself proposes Eteocretan with a question mark. It is
not converted into a known language assignment or an invented single object.

Required next work: acquire reusable primary Dreros editions, reconcile the
Guarducci/Duhoux/Brown readings by line, independently collate historical
page encodings, inventory and classify Azoria items, and document later
finds. Keep each source's assertions and dates distinct. A reviewer must
be able to compare exact source-page sign shapes and all alternative versions.

Psychro authenticity claims remain attributed and disputed. Arkalochori
has a disputed Bronze Age script assignment and is a comparison object,
not an Eteocretan inscription. No shared ancestry with Linear A or other
languages is accepted from geographical proximity or the name Eteocretan.

New analytical admission requires an attributed source version, rights
clearance, explicitly collated reading and uncertainty spans, a stable object
identity, a record of disagreements, and independent epigraphic review.
Enabling frequency cannot turn a damaged string into an established word.
