# Rights-wall audit — 2026-10-06

Purpose: challenge the repository's existing rights-dominant readiness claim by testing every residual route for additional lawful public evidence.

## Guarducci 1942 / Praisos

**Result: access blocker reduced; redistribution-rights blocker remains.**

The University of Crete Anemi catalogue publicly exposes *Inscriptiones Creticae* III (1942), resource 000070579, digital file 000070579_3.pdf, 101 pages, digitized 2003-12-10. This corrects the earlier checkpoint in which delivery of the file failed.

A Greek government open-data catalogue also exposes a downloadable item described as Guarducci III. Inspection shows that this particular 11-page PDF is a later Greek-language review of Guarducci III (printed pp. 302–312), **not the edition itself**. It must not be used as a substitute for the Anemi volume.

Project consequence:
- lawful public *access route* to Guarducci III is established through Anemi;
- no Guarducci text, apparatus, facsimile, or scan is redistributed by this project on that basis alone;
- systematic structured derivative/public redistribution still requires a source-specific rights determination;
- bibliographic facts and record-level factual metadata may be recorded with attribution.

## Praisos public object route

The Heraklion Archaeological Museum now exposes a searchable public digital catalogue with stable inventory identifiers for many Praisos objects. A targeted public search did not return a museum catalogue record for the Eteocretan inscriptions themselves. Therefore no Praisos inscription accession is inferred from nearby Praisos objects or from an image filename.

The BSA archive continues to provide a stable archival identity for the Praisos 2 / nomos-fragment copy negative (BSA SPHS/1/2816.7202). It remains a photographic/archive witness, not a museum accession and not an independent ancient object.

## Dreros object route

Public secondary sources conflict on the post-excavation whereabouts of Dreros inscriptions (Neapolis, Heraklion, missing/lost). This pass found no authoritative museum inventory record that safely resolves the Eteocretan objects. The project therefore preserves the conflict and does not assign an accession by inference.

## Azoria

A public Society for Classical Studies abstract independently describes two inscribed pithos handles as probably Eteocretan. This strengthens the *existence/classification lead* but does not supply excavation/museum identifiers, readings, image rights, or independent epigraphic certification. The existing D300 upper/lower candidate split remains appropriate.

## Outcome

No new reading is admitted. No disputed object is promoted. Guarducci access is no longer accurately described as unavailable, but rights for systematic derivative redistribution remain unresolved. The remaining growth routes are now more precisely separated into:

1. accessible-but-rights-limited source inspection;
2. inaccessible/restricted critical source evidence;
3. unresolved authoritative object identity;
4. downstream human epigraphic adjudication.

This audit narrows the legal wall without moving it by assertion.
